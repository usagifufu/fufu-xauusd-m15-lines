# fufu XAUUSD M15 单画线

TradingView **Pine v5** 指标。在黄金 15 分钟图上自动画出四类元素：

| 元素 | 画什么 | 用途 |
|---|---|---|
| **ZigZag 摆动折线** | 连接交替的已确认摆动高低点 | 看价格结构路径，判断现在是哪个方向在走 |
| **第N阻力 / 第N支撑** | 摆动点按「离现价远近」排序分档，第1 = 离现价最近 | 到哪儿该警惕 |
| **多空关键位** | 结构状态机给出的方向分界 | 现在是哪一边 + 结构止损位 |
| **触及信号箭头** | 下探关键位后收回 → 红 ↑；上冲关键位后回落 → 绿 ↓ | 关键位有没有真的生效 |

**配色即角色：🔵 蓝线 = 结构位，🔴 红线 = 多空关键位，🔵 折线 = ZigZag 摆动路径。**

> 注意这套跟本系列的 BTC / ETH 脚本**不是同一套标签体系**。BTC / ETH 那套是「已证实 / 未经测试 / 变节者 × 阻力·做空 / 支撑·做多」八类，用的是红涨绿跌；
> 这套是照 TradingView 上的参考图画法复刻的「第N阻力 / 第N支撑 + 多空关键位」，结构线统一蓝色、关键位红色。不要互相套用。

## 一、四个元素分别怎么算

### 1. ZigZag 摆动折线

用 `ta.pivothigh / ta.pivotlow`（左右各 10 根）找摆动点，然后**强制交替**：

- 相邻同类型（都是高点）→ 只保留更极端的那个
- 相邻异类型（高 ← → 低）→ 两点的幅度必须 ≥ 「ZigZag 最小摆动幅度」（默认 **0.80%**），不够就忽略

所以折线一定是 高-低-高-低 交替的，不会出现两个连续高点。

### 2. 第N阻力 / 第N支撑

**档位候选只用 ZigZag 折点**，不用全部摆动点。

这一点是拿参考图反推出来的：图上 10/9 那三条支撑 `4146.02 / 4105.62 / 4066.09`，正对应 ZigZag 的 `4147.81 / 4106.39 / 4073.04`。
如果改用「全部摆动点」，会混进一堆噪声小摆动（`4181.70 / 4155.00 / 4130.75`），把真正的结构位挤掉。

分档流程：

```
ZigZag 折点
   ↓ 按现价上下分开（剔除离现价 ±0.20% 以内的）
   ↓ 按离现价距离升序
   ↓ 同侧最小间距 0.50% 去重（近的优先）
   ↓ 取前 N 个，编号 第1 / 第2 / 第3
```

**第1 = 离现价最近的那条。** 价格走过去之后原来的第1会被顶掉，后面的依次递补，所以编号是**动态**的，不是固定的。

### 3. 多空关键位

结构状态机，逐根 K 线累积：

| 当前方向 | 关键位取值 | 换边条件 |
|---|---|---|
| 做多 | 最近一个**已确认的摆动低点** | 收盘跌破 关键位 ×（1 − 穿越确认%）→ 转空 |
| 做空 | 最近一个**已确认的摆动高点** | 收盘突破 关键位 ×（1 + 穿越确认%）→ 转多 |

方向判定**只看本方向那一侧的枢轴**。不这样写的话，价格在区间里来回震荡时两侧条件会轮流成立，方向会反复翻。

关键位用的是**独立的一套枢轴**（左右各 14 根），比画线用的 10 更粗：画线找的是具体价位，关键位判的是大结构。

### 4. 触及信号箭头

对每条当前档位线，从最新往回扫：

- **下探后收回** → `低点 ≤ 线×(1+容差)` 且 `收盘 > 线` 且 `开盘 ≥ 线` → 红 ↑（支撑成立）
- **上冲后回落** → `高点 ≥ 线×(1−容差)` 且 `收盘 < 线` 且 `开盘 ≤ 线` → 绿 ↓（阻力成立）

每条线只标**最近的最多 2 次**，避免箭头糊满屏。

## 二、参数

### ① 识别参数

| 参数 | 默认 | 说明 |
|---|---|---|
| 摆动点 左/右K线数 | 10 / 10 | 左右各 N 根内的极值才算摆动点 |
| **识别回看根数** | **2500** | 见下方「两个关键参数」 |
| 贴近现价忽略 % | 0.20 | 离现价太近的摆动点不参与分档 |
| **ZigZag 最小摆动幅度 %** | **0.80** | 见下方「两个关键参数」 |

### ② 分档

| 参数 | 默认 | 说明 |
|---|---|---|
| 每侧最多档位 | 3 | 参考图多数时点是第1~第3，偶尔出现第4 |
| 同侧最小间距 % | 0.50 | 两条线挨太近只留近的那条 |
| 结构线向左画多少根 | 500 | 15m × 500 ≈ 5.2 天 |

### ③ 多空关键位

| 参数 | 默认 | 说明 |
|---|---|---|
| 显示多空关键位 | 开 | |
| 关键位 左/右K线数 | 14 / 14 | 比画线用的 10 粗 |
| 穿越确认 % | 0.80 | 见下方「黄金的噪声」 |

### ④ 触及信号

| 参数 | 默认 | 说明 |
|---|---|---|
| 显示触及信号 | 开 | |
| 触及容差 % | 0.20 | 进入关键位 ±这个幅度算触及 |
| 信号回看根数 | 260 | 15m × 260 ≈ 2.7 天 |
| 每条线最多几个信号 | 2 | |

### ⑤ 颜色与样式

| 参数 | 默认 |
|---|---|
| 阻力线 / 支撑线 | 🔵 `#2962ff` |
| 多空关键位 | 🔴 `#f23645` |
| ZigZag 折线 | 🔵 `#5b8dff` |
| 做多信号 / 做空信号 | 🔴 `#f85149` / 🟢 `#3fb950` |
| 结构线宽 / 关键位线宽 | 1 / 2 |
| 向右延长K线数 | 60（15m × 60 = 15 小时） |

## 三、两个关键参数，别随手改

### 「识别回看根数」默认 2500，不是 900

参考图上 10/6 ~ 10/12 一直挂着 `第3阻力 4275.89` 和 `第4阻力 4316.10`，价格那几天根本没到过这个高度。
原因：**它们是一个多月前（9/25 ~ 9/27）的历史摆动点**。

| 回看窗口 | 能看到的位 |
|---|---|
| 900 根（9.4 天） | 最高只到 4228 |
| 2500 根（26 天） | 4275 / 4316 都出来了 |

窗口调小，图上的高位会集体消失。

### 「ZigZag 最小摆动幅度」默认 0.80%

拿 4 个参考时点（10/6、10/7、10/9、10/13）跟截图上的价位逐条比对扫出来的：

| 幅度 | ZigZag 折点数 | 档位命中 |
|---|---|---|
| 0.60% | 74 | 18 / 23 |
| 0.70% | 74 | 18 / 23 |
| **0.80%** | **48** | **19 / 23** |

调小会让噪声小摆动挤进「第N档位」，把真正的结构位顶掉。

## 四、黄金的噪声比 BTC 大得多

这是本项目里最反直觉的一条发现。

多空关键位的「穿越确认幅度」在本系列 BTC 脚本里是 **0.15%**（900 根内只翻 6 次方向）。同样的 0.15% 用到黄金上：

| 品种 / 参数 | 翻转次数 |
|---|---|
| BTC 14 / 0.15% | 6 次 |
| **XAU 14 / 0.15%** | **47 次** ← 价格稍有回踩就换边，完全没法用 |
| XAU 14 / 0.80% | 9 次 |

黄金 15 分钟的日内噪声远大于 BTC，穿越确认必须放宽到 **0.80%** 才能得到可用的方向。

## 五、跟参考图的对照验证

用 4 个可对齐的截图时点逐条比对（±0.5% 内算命中）：

```
10-09 15:48   现价 4199.16（模型 4198.84，差 -0.32）
   阻力 图上  4210.10  4228.55  4275.89  4316.10
        模型   —       4226.82  4288.72  4316.20      ← 4316.20 ↔ 4316.10，差 0.1
   支撑 图上  4146.02  4105.62  4066.09
        模型  4155.00  4130.75  4108.80

10-13 12:04   命中 4 / 6
总体          19 / 23 （82.6%）
```

> 说明：参考图出自一个闭源指标，无法反推它的全部细节（例如它的支撑偶尔会取到更远的位），
> 所以做不到逐条完全一致。上面这套规则是「能对上绝大多数、且逻辑自洽」的最优解。

数据源用的是币安 **XAUUSDT** 永续，与 TradingView 上的 XAUUSD 现货报价相差 **0.1% ~ 0.3%**（10/9 同一时刻只差 3.83 美元），足以用来做逻辑对照。

## 六、使用注意

1. **TradingView 上加载到 `XAUUSD` 图表**（OANDA / FX 的现货黄金）。脚本内的显示名同样是 `XAUUSD`，与要加载的标的保持一致。数据源用的是币安 XAUUSDT 永续，与 TradingView 的 XAUUSD 现货相差 0.1% ~ 0.3%。
2. **只在最后一根 K 线重算重画**（`barstate.islast`），历史 K 线上不画线。这是刻意设计，避免把几百根历史 K 线都画满。
3. **状态机写在全局作用域**，只有绘制在 `barstate.islast` 里。这条很关键：如果把状态机也塞进 `barstate.islast`，它只在末根算一次，方向会永远停在「尚未判定」。
4. **切换周期后要重看一下输出条数**。「识别回看根数」默认 2500 是按 15m 调的，切到 5m 相当于只回看 8.7 天，切到 1H 相当于回看 104 天。按需调整。
5. **ZigZag 的最后一个折点会变**。这是 ZigZag 的固有特性（最新一段还没被确认），不是 bug。
